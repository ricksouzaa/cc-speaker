# Segurança

O plugin roda só na sua máquina: o motor de voz é local, a única rede usada é o download do motor e do modelo na instalação.

Achou uma falha de segurança? Não abra uma issue pública com os detalhes. Use o relato privado de vulnerabilidade do GitHub (aba Security do repositório, "Report a vulnerability") ou escreva ao Ricardo pelo e-mail do perfil dele no GitHub.
