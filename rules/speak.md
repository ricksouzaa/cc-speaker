# Spoken reply

The `speak` Stop hook reads each reply aloud: by default only its last line `🔊 <resumo>` (`speak mode summary`); or the whole prose and tables, without code blocks, paths, links and file names (`speak mode full`).

- {line}
- In it: no code, file names, paths, commands, command output, numbers of lines, links or acronyms; it is heard, not read.
- Prose that explains a code block says it in words, so the reading still makes sense without the block.
- By default (`speak mic wait`) only dictation interrupts the reading: the voice does not speak while the microphone is recording (dictation, video call) and is cut if a recording starts while it speaks. With `speak mic play` the voice speaks even with the microphone in use and nothing cuts it; with `speak mic auto` the same, and when the microphone becomes free (the meeting ends) the choice goes back to `wait` by itself. A new speech, from any session, waits its turn in a queue; a new message does not cut it.
- When the voice is off, leave the line out, so no text is written for nothing: the new-message hook says so in a `speak:` note that holds for that message (voice off here or for all, or no engine), and so does a `speak off` you just ran. Without the note, or after a `speak on`, the line is back.
- Every slash command below can also be asked in words, typed or dictated, in any phrasing ("voz", "narração", "narrador", "leitura", "áudio" all mean the voice). Run the matching `speak` command through Bash and confirm in one sentence what now holds. It acts on this session only; when they say all sessions, everything or global ("todas as sessões", "tudo", "geral"), add `all` (on, off, mode, size, mic). When the request names no choice ("muda a voz", "ajusta o tamanho do resumo"), ask with AskUserQuestion, one question per choice (the options of the matching setting, then scope: "Só esta sessão" or "Todas as sessões"), then run it.
  - Turn on or off ("ativa a narração", "desativa a narração", "silêncio", "volta a falar"): `speak on` or `speak off`.
  - Cut the speech playing now and empty the queue, keeping the voice on ("para de falar agora", "corta essa fala", "pula"): `speak stop`.
  - Only the summary or the whole reply ("lê só o resumo", "lê tudo"): `speak mode summary` or `speak mode full`.
  - A bigger or smaller summary ("resumo maior", "resumo curto"): `speak size large`, `speak size medium` or `speak size small`; from then on the new size holds for the `🔊` line, as `speak off` holds for the voice.
  - What the voice does while the microphone is in use ("toca durante a reunião", "pode falar na reunião", "fala mesmo com o microfone ligado"): `speak mic play` (stays until changed) or `speak mic auto` (only for this meeting); "volta a esperar o microfone": `speak mic wait`. When the request does not say which of the two, ask with AskUserQuestion. Say once that the microphone may pick up the voice and the people in the meeting hear it. On Linux, dictating in Claude Code (holding the space bar) still holds and cuts the speech in both; on the Mac nothing does.
  - Hear the last speech of this session again ("repete", "fala de novo", "não entendi, repete"): `speak again` (as it played). The whole reply ("lê a resposta inteira", "lê o texto completo"): `speak again full`. Only the summary line again ("lê só o resumo de novo"): `speak again summary`. Mind the difference: "lê só o resumo" without "de novo" is the setting for the next replies, `speak mode summary`, not a repetition. It plays even with the voice off; say in one sentence what is playing, or that there is nothing to repeat yet.
  - Pause the speech playing now ("pausa", "pausar a fala", "espera um pouco aí"): `speak pause`. It freezes the speech at the exact point, whoever's session it is, and the next speech in the queue may play meanwhile. It stays paused until asked: "continua", "continuar de onde parou", "volta a falar de onde parou": `speak resume` (at once when nothing else plays; else it goes before the queue and continues when the speech playing ends). Say in one sentence what happened, or that nothing was playing or paused. "Pula" and "para" are not a pause: they cut (`speak stop`).
  - Change the voice ("troca para a voz do Alex", "quero uma voz feminina"): `speak voice <name>` (dora, alex or santa).
  - How the voice is set ("como está a narração?"): `speak status`, then say it in plain words.
  - Update the plugin ("atualiza o plugin da voz", "atualiza o speak"): `speak update`, with a timeout of 300000 ms (two `claude` commands, up to 120 s each). Say its answer in one sentence; the new version only holds after the human types `/reload-plugins` (you cannot) or opens a new session.
  - Install the engine ("instala a voz"): `speak install`, with a timeout of 600000 ms.
- The slash command `/speak` exists for the human: alone it opens a side panel that already has the keyboard (terminal and VS Code), one native list per row, a "Ouvir de novo" row with the buttons Resumo and Resposta inteira that play at once (the same two buttons also show under the last reply once its turn ends; while this session's speech plays, the button of its mode becomes "⏸ Pausar", and "▶ Continuar" when it is paused) (Tab changes the row, Enter picks the value; Esc or the Fechar button closes); `/speak on`, `off`, `mode`, `size`, `voice`, `mic`, `again` (`summary` or `full`), `pause`, `resume`, `status`, `stop`, `install` and `update` also work typed (`all` at the end of on, off, mode, size and mic for every session). The module answers it without you; do not run it for the human.
- Subagent reports carry no such line; only the session that talks to the human writes it.
