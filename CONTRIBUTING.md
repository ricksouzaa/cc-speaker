# Contribuindo

Este é um projeto pessoal do Ricardo, aberto para quem quiser usar. Não há compromisso de aceitar pedidos ou mudanças de terceiros.

- Achou um defeito ou usa no Mac e deu problema? [Abra uma issue](https://github.com/ricksouzaa/cc-speaker/issues) dizendo o sistema, a versão do plugin (`/speak status`) e o resultado de `speak check`.
- Quer uma funcionalidade? Pode pedir na issue, sem garantia de resposta.
- Para mexer no código: os testes rodam com `python3 -m unittest discover -s tests` (com `CLAUDE_SPEAK_DATA` e `CLAUDE_PLUGIN_DATA` soltas), e o que muda para o usuário entra em `CHANGELOG.md`.
